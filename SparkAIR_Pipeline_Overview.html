Once per file · 3 prompts

Understand the deal

IN   the deal's review documents (RAMP / annual review), searched by RAG

1a  Deal facts

What is this transaction? OUT  six fixed lines — transaction & structure, review type, jurisdiction, classes & ratings, models used, conflicts noticed.

1b  Criteria cited

Which criteria (and which vintage) does the file itself cite? OUT  the citing sentences verbatim + one line of article names with dates — the current-version check.

1c  Precondition check

All 28 questions in one call: does each question's own precondition hold for this deal? OUT  per question — applies / does not apply / cannot tell / no condition, each with the condition and the deciding fact quoted.

2
Once per question · Step A

Find the evidence

IN   one FRT question + its numbered search guide (from the criteria-mapping workbook: what the file should contain if each criteria point was applied) + the deal documents, searched by RAG

DO  locate the relevant passages and reproduce them verbatim, tagging each passage to the guide item(s) it addresses — no summarising, no judging

OUT quoted evidence sections + an explicit NOT FOUND list of the guide items with no retrieved passage

→
3
Once per question · Step B

Judge against criteria

IN   the question + its verbatim criteria text (from the mapping workbook) + the Step-2 evidence + the deal profile with only this question's precondition line

DO  compare evidence to criteria — with no access to the documents: it can only use what step 2 actually found, so missing evidence surfaces as TBD instead of being papered over

OUT a fixed answer schema — Answer (Yes / No / N/A / TBD / Yes-deviated) · rationale · the criteria sentence relied on · the file passage relied on · reviewer follow-up · confidence

steps 2 – 3 repeat once for each of the 28 template questions
